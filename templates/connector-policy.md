# Suggested Default Policy

| Service | Default tools | Writes | Deletes |
| --- | --- | --- | --- |
| Gmail | profile, search, read | off | off |
| Feishu | document/wiki/sheet/table read | off | off |
| QQ Mail | profile, folders, search, read | off | off |

Enable write or delete tools only for a specific task and restore the read-only policy afterward.
